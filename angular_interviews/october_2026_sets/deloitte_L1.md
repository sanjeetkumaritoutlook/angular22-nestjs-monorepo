Deloitte L1 Interview — Angular Developer Questions I Remember

I recently went through a Deloitte L1 interview, and I couldn’t remember every question afterward.

But I did remember a significant portion of them, so I documented them.

The interesting part was that the interview wasn’t only about Angular.

The questions covered:

## HTML

* HTML tags and attributes
* Calling APIs from HTML
* Embedding one HTML page inside another
* Semantic HTML
* Canvas
* Block vs inline elements

## CSS / SCSS

* CSS style policies
* CSS vs SCSS
* hidden vs display: none
* CSS position properties

## JavaScript

* Promises
* Hoisting
* Event Loop
* Debounce vs Throttle
* Promises vs Observables

## Angular

* NgModule
* Components
* Services
* Singleton pattern
* Directives
* Data binding
* Providers vs ViewProviders
* Module vs Service vs Component

The interview also included scenario-based questions, such as:

* How would you optimize a dashboard handling a large amount of data?
* How would you optimize search?
* What was the biggest challenge in your recent project?
* What coding practices do you follow?
* What is your thought process when debugging an issue?

These questions are a good reminder that experienced frontend interviews aren’t only about memorizing Angular APIs.

They test whether you understand the fundamentals, architecture, performance, debugging and your own project experience.
