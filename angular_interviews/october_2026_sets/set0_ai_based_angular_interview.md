AI-based L1 interview for an Angular Developer position at Zetamicron Technologies Private Limited, for a 3.7 years experience role.

Here are the questions asked during the AI interview:

1. Can you explain when you would provide a service at the root level vs at the component level and give a concrete example, such as a logging service used across the application vs a component-specific service?

2. Describe strategies to avoid memory leaks with root services, guards, interceptors, and long-lived subscriptions?

3.Can you list specific techniques you use for route guards, interceptors, and long-lived subscriptions to prevent memory leaks, for example, unsubscribing patterns, use of takeUntil, using providedIn: 'root' services vs component-provided services, or use of the async pipe?

4. How would you design a complex form using Reactive Forms with dynamic controls, validations, and NgRx-driven state?

5. Describe your typical Git workflow for a single feature branch to production?

6. How do you perform an interactive rebase to clean up commits before opening a PR?

7. Explain securing API calls with token refresh flows and retrying failed requests safely?

8. How do you design client-side caching and invalidation strategies for REST backend data?

9. Explain error-handling strategies in RxJS pipelines for resilient UI flows?

10. Propose a testing strategy for complex RxJS logic including marble testing and integration with Angular TestBed?

11. How do interfaces differ from types in TypeScript and when would you use each?

12. How do you enable strict typing in a project and handle legacy untyped code?

13. Propose a strategy to migrate a large Angular codebase from weak types to full strict TypeScript without blocking delivery?

14. Describe how you collaborate with backend developers to troubleshoot an integration issue?

15. Tell me about a time you gave or received constructive feedback during a code review?

The AI interview was focused more on practical and real-world problem solving rather than just basic Angular definitions.
