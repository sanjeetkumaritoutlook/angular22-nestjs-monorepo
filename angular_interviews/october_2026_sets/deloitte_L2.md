Technical Round for a 5+ YOE Angular role at Deloitte. Sharing them here—it may help others preparing for interviews.
🔄 Repost to help other Angular developers preparing for interviews.
```
1) What's your experience using AI models in your day-to-day development?
2) Which AI tools have you used (Claude, GitHub Copilot, etc.)?
3) What skills are important when working with AI models?
4) What are MCP Servers?
5) With limited tokens available, how would you get work done while minimizing token usage?
6) What are the benefits of Micro Frontends over a Monolithic architecture?
7) How would you set up a Micro Frontend architecture? Can Angular and React coexist in the same project?
8) Have you used Module Federation?
9) Have you worked with Signals in Angular?
10) What types of Signals are available?
11) If a Signal's state changes, how would you detect it?
12) Have you worked on a project where the navbar/menu was dynamic based on user roles?
13) How would you implement a role-based menu?
14) Suppose you need to display thousands of records with images coming from an API. What would be your approach?
15) Have you created any Custom Directives?
16) Is it possible to generate HTML using a Custom Directive? How?
17) What are Pure and Impure Pipes?
18) Have you used the Async Pipe?
19) How would you share data between components that do not have a parent-child relationship?
20) How would you implement API caching in Angular? For example, if a user searches the same ID twice, the second request should not hit the API again.
21) Have you worked in a project where multiple teams from different organizations owned different modules, and your feature had dependencies on another team?
22) You have Dev, QA, UAT, and Production environments. How do you manage different API URLs, keys, and environment-specific configurations during deployment?
23) Do you have experience resolving Sonar issues?
24) How does code review happen in your project?
25) The UI team and API team start the same sprint together. Your UI is completed, but the APIs are not ready. How would you test your feature until the APIs are available?
26) How you are achieving code coverage, what percentage you have to achieve ?
```
