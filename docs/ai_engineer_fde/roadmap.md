## 🎯MONTH 1: Python, Git & Engineering Basics

### Week 1: Python Fundamentals
```
Learn variables, data types, conditionals, and loops in Python.
Understand how Python executes code line by line.
Write simple programs to build logic and confidence.
Practice reading and understanding error messages.
Build: Basic calculator, number guessing game.
```
### Week 2: Functions & Data Structures
```
Learn functions, arguments, return values, and scope.
Work with lists, dictionaries, tuples, and sets.
Learn why reusable functions matter.
Start writing cleaner, readable code.
Build: Student marks analyzer, to-do list app.
```
### Week 3: Writing Real Python Code
```
Learn modules, imports, and basic file handling.
Understand exceptions and error handling.
Learn debugging techniques instead of trial-and-error.
Write scripts that automate small tasks.
Build: File organizer or CSV processing script.
```
### Week 4: Git, GitHub & Collaboration
```
Learn what version control is and why it matters.
Practice git add, commit, push, pull, and branching.
Create a GitHub repository and write a proper README.
Understand how engineers collaborate using Git.
Build: Push all Month-1 projects to GitHub.
```

## 🎯 MONTH 2: Data, Text & Embeddings Foundations
### Week 5: Data Handling with Pandas
```
Learn how to load CSV and Excel files using Pandas.
Filter, sort, and group data.
Understand datasets and columns conceptually.
Practice exploratory data analysis.
Build: Analyze a small real dataset.
```
### Week 6: Data Cleaning & Preparation
```
Handle missing values and duplicates.
Learn basic feature engineering.
Understand why clean data matters more than models.
Learn scaling and normalization intuition.
Build: Clean and prepare a messy dataset.
```
### Week 7: Text Processing Basics
```
Understand unstructured text data.
Learn tokenization, stopwords, stemming, and lemmatization.
Practice basic NLP preprocessing pipelines.
Learn why raw text cannot be used directly.
Build: Text cleaning pipeline.
```
### Week 8: Embeddings & Similarity
```
Learn what embeddings are and why they work.
Understand cosine similarity intuitively.
Generate embeddings using APIs or libraries.
Perform semantic similarity search.
Build: Text similarity search tool.
```
## 🎯 MONTH 3: Machine Learning Foundations
### Week 9: ML Basics & Problem Framing
```
Learn what Machine Learning is and what it is not.
Understand supervised vs unsupervised learning.
Learn training vs testing data.
Understand common ML use cases.
Build: ML problem definition document.
```
### Week 10: Core ML Models
```
Learn linear regression and logistic regression.
Understand KNN and decision trees intuitively.
Learn when to use which model.
Train simple models using scikit-learn.
Build: House price or classification model.
```
### Week 11: Model Evaluation
```
Learn accuracy, precision, recall, and F1 score.
Understand confusion matrices.
Learn cross-validation conceptually.
Analyze model failures.

Build: Model evaluation report.
```
### Week 12: ML Best Practices
```
Understand overfitting and underfitting.
Learn bias-variance tradeoff.
Learn basic hyperparameter tuning.
Build an end-to-end ML pipeline.
Build: Final ML mini-project.
```

```

```

Learn prompt iteration techniques.

```

```

```
Learn hallucinations and bias.
Understand prompt injection attacks.
Learn safe prompting and guardrails.
Build: Safer chatbot with constraints.
```
